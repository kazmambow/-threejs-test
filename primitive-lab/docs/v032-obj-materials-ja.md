# v0.32 OBJ / MTL マテリアル読み込み

OBJ ImportからOBJ・MTL・参照画像をまとめて選択してください。ブラウザは選択していないローカルの別ファイルを自動で開けません。画像がサブフォルダにある場合も、該当画像を選択対象に含めてください。同じファイル名の画像が複数ある場合は一意に特定できないことがあります。

OBJのusemtlを保持し、面グループごとに内部マテリアルへ割り当てます。材質一覧・編集・削除・未使用判定・Undoに対応します。オブジェクトへ別材質をドロップすると従来どおり全体がその材質になります。

MTL対応: Kd / d / Tr / Ns（roughnessに近似換算）/ Ni / Pr / Pm / Ke、map_Kd / map_Pr / map_Pm / norm / map_Kn / disp / map_d / map_Ke。画像は既存のPNG/JPEG/EXR等セッション資産に登録します。MTLのマップオプションの変換値は再現しません。Bump高さ画像から法線への変換は未対応で警告します。Blenderのノード・プロシージャル材質の再現は対象外です。必要な画像はBlender側でベイクしてください。

検証: 実OBJLoaderを使う自動テストで複数材質分割・画像参照・透明度編集・Tint・材質置換・Undo・削除。公開ブラウザ上でOBJ+MTL+PNGのファイル選択、色付き面と半透明面の別材質描画、サムネイル、コンソールエラーなしを確認。利用者のBlender実ファイル自体は未検証です。

参考: https://threejs.org/docs/pages/MTLLoader.html
