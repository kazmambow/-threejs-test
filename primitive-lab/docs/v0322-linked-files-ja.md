# v0.32.2 リンクファイル

ヘッダー「リンクファイル」で参照画像一覧、元のMTL記載パス、使用マテリアル/チャンネル、現在読み込み済みのファイル名、読込済み/不足を表示します。OBJ読み込み時に画像不足があっても参照を保持し、このウィンドウを開きます。

「画像を一括選択」で別フォルダの画像を後から選択するか、「テクスチャフォルダを指定」でサブフォルダ込みの画像から不足参照を名前で照合します。同名候補が複数ある場合は自動リンクしません。各行「画像を指定」「差し替え」で異なる名前の画像へ手動変更できます。再リンクはUndo/Redo対象です。

表示する元パスはMTLに記載された値です。ブラウザで選択したファイルの絶対パスは取得できないため、選択時のファイル名/フォルダ内相対パスを併記します。ディスクからの削除を継続監視する機能ではありません。画像はセッションのみ保持します。

旧v0.32.1以前では不足参照自体が消えていたため、既存の読み込み済みシーンへ遡って参照を復元できません。新しい版でOBJ+MTLを再度読み込んでください。

テスト: 不足参照保持、パス表示、同名重複保護、一括再リンク、別名への個別リンク、Undo/Redo。
